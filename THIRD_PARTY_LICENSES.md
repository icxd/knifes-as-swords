# Third-party software shipped with this mod

The mod's jar contains the following library, unchanged, under `META-INF/jars/`.

- What it is used for: decoding the knife sounds, which the player's own game files hold as MP3.

# Tools the mod fetches but does not ship

Source2Viewer-CLI (ValveResourceFormat, MIT) converts the game's files on the player's machine.
It is downloaded from its own project page after the player agrees, and is not part of this mod.
